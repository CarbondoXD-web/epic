# 机械臂直接取料

主工程：`D:\unity\EPIC`。场景：`Assets/Scenes/FactoryLayout.unity`。

成品货架位于地轨物理末端，开口朝向机械臂（世界 -Z）。货架采用三层开放存放结构，每层四个定位托盘，共十二位；依次填满下、中、上层。用户提供的 `storage rack.fbx` 本体保留为背部支撑，原文件不变；为容纳阶梯轴和夹爪，增加独立承重层板与开放的正面存取空间。滑台停在轨道支撑范围内，机械臂在架外调整腕部姿态，再从正面进入对应层。放稳、松爪后仅抬离定位座，再水平退出，到架外收臂，避免向上撤离碰到上一层。

已移除原料输送带、备料台和原三层存储架。中央长地轨保留，入口侧设有三列四排、共十二个独立定位座的集中原料台，台面约为 1.14 × 1.58 米。机械臂先取靠近地轨的一列，再依次取后面的列，从架上夹紧原料、抬升撤离，再携件到机床上料。加工完成后取出阶梯轴并放入成品槽位。每个原料位置对应一件独立工件，取走后留下空位。

单击机械臂或底部“开始搬运”开始一批十二件；“暂停/继续”或空格控制暂停；“重新开始”恢复原料和设备。相机右键旋转、中键平移、滚轮缩放，1 全景、2 俯视、3 入口视角、4 成品货架正面视角。第一版每台机床两件，暂不启用竞赛故障。

底部控制栏提供 0.5×、1×、1.5×、2×、3× 流程倍速。默认 1× 沿用当前速度，可在运行中切换；统一影响机械臂、地轨、夹爪、机床门和加工进度，不影响相机和单击/双击判定。暂停时切换倍速仍保持暂停；重新开始保留所选倍速，重新进入播放模式恢复 1×。机床状态面板的预计剩余时间随当前倍速调整。

延续原单机床场景的天空、地面与灯光风格，正常指示灯为绿色。原 `RobotMachineGrab` 单机床回归场景保留。


加工音效：每台机床仅在主轴加工状态播放循环声，开停机有短渐变；暂停、安全停止和订单完成立即静音。多台机床同时加工时自动限制混合音量，默认强度为 0.14；可在整线控制对象的 FactoryMachiningAudio 组件调节 Volume。声音定位在各台机床主轴，采用全三维距离衰减，2 米以内保留近场音量，拉远逐渐减轻，32 米外静音。音频由本地合成的主轴谐波与切削噪声组成，无外部录音依赖。

2026-10-28 验证：十二件分别放入三层、每层四位；五档倍速均覆盖，全部机床各加工两件。连续运动扫描 contacts=0，成品无重叠，所有支承间隙约 3mm。携件且有机床加工时暂停，音效即时归零；恢复后完整订单继续完成。
